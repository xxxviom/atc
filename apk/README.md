# Довідник ATC — Android

Оболонка Capacitor навколо веб-застосунку з кореня репозиторію. Android-проєкт не зберігається в репозиторії:
workflow `.github/workflows/apk.yml` копіює веб-файли в `apk/www`, створює проєкт і збирає APK.

Готовий файл: **Releases → «Довідник ATC (APK)»** (`dovidnyk-atc.apk`).
Збірка запускається після змін на `main` і вручну (Actions → Run workflow).
APK підписаний debug-ключем, тому перед установкою треба дозволити встановлення з невідомих джерел.
